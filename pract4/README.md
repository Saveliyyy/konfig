# Практическое занятие №4 — решения

Ассемблер и интерпретатор одноадресной машины (AWK Programming Language, разд. 6.1),
стековая и регистровая ВМ, WebAssembly.

Требования: Python 3.8+; для задач 10–11 — Node.js 16+ или любой современный браузер.
Сторонние библиотеки не нужны.

Все Python-команды запускайте **из этой папки** (задачи 2–4 импортируют предыдущие).

## Состав

| Файл | Задача | Что делает |
|---|---|---|
| `sum.asm` | — | Исходный текст примера (сумма чисел до нуля) |
| `task1.py` | 1 | Первый проход: таблица символов + символьный промежуточный код |
| `task2.py` | 2 | Второй проход: метки → адреса |
| `task3.py` | 3 | Кодирование в числа `код*1000 + аргумент` |
| `task4.py` | 4 | Интерпретатор закодированной программы |
| `task5.py` | 5 | Стековая ВМ: дискриминант (`sub`, `mul`, `dup`, `print_`) |
| `task6.py` | 6 | Стековая ВМ с памятью, вводом/выводом и переходами — пример из задачи 1 |
| `task7.py` | 7 | Регистровая ВМ: дискриминант (`sub`, `mul`, `print_`) |
| `task8.py` | 8 | Регистровая ВМ с вводом/выводом и переходами — пример из задачи 1 |
| `task9.py` | 9 | Бинарный формат команд стековой ВМ, сохранение/загрузка файла |
| `task10/` | 10 | `S.c` (Си), `S.wat` (ручной Wasm), `S.wasm` (готовый модуль), `test_S.js` |
| `task11/` | 11 | `index.html` (страница), `sum.c`, `sum.wat`, `sum.wasm`, `test_sum.js` |

## Запуск

### Задачи 1–4
```
python task1.py          # таблица символов и промежуточный код
python task2.py          # код с адресами
python task3.py          # [3010, 4011, 1000, 8007, ...]
python task4.py          # вводите числа, 0 — конец; выведет сумму
```
Другой исходник можно передать аргументом: `python task4.py my.asm`.

### Задачи 5–9
```
python task5.py          # 1 и -23  (D для x²-5x+6 и 2x²+3x+4)
python task6.py          # ввод чисел до 0 -> сумма
python task7.py          # 1 и -23
python task8.py          # ввод чисел до 0 -> сумма
python task9.py          # сохраняет sum.bin, загружает, сверяет и запускает
```

Формат файла задачи 9: заголовок `SVM1` (4 байта) + число команд (uint16),
далее на каждую команду 1 байт кода операции и 4 байта аргумента (int32, little-endian).

### Задача 10
Вариант 1 — wasmfiddle.com: вставить код из `task10/S.c` в окно C, нажать **Build**,
в окно JS вписать `console.log(wasmInstance.exports.S(10));` и нажать **Run** → `55`.

Вариант 2 — локально: `node task10/test_S.js` → `55`.

Пересборка (нужен clang с целью wasm32):
```
clang --target=wasm32 -O2 -nostdlib -Wl,--no-entry -Wl,--export=S -o S.wasm S.c
```

### Задача 11
Открыть `task11/index.html` в браузере двойным щелчком, нажать **Запустить**,
вводить числа в окнах `prompt`, 0 — конец; сумма покажется в `alert`.
Модуль встроен в страницу в base64, поэтому сервер не нужен.

Проверка без браузера: `node task11/test_sum.js` → `-> 45`.

`sum.wat` — тот же модуль вручную, команды подписаны соответствиями из `sum.asm`.
Его можно собрать через `wat2wasm sum.wat` (WABT) или в онлайн-конвертере.
